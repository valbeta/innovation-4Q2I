# 4Q2I｜创新四问模型

**4Q2I 是一套创新价值系统验证框架（Innovation Value System Validation Framework）。** 它帮助团队从机会识别出发，构建价值创造逻辑，验证利益相关者可赞性，并检验价值系统能否在真实环境中运行。

## 四个问题

1. **Where do we stand?** — 机会识别
2. **Where are we going?** — 价值创造逻辑
3. **Who is with us — and why?** — 利益相关者验证
4. **How do we get there?** — 价值系统验证

四个阶段形成有证据和决策门槛的推进顺序，同时允许团队在新证据改变判断时回到前序问题。4Q2I 不是要求项目使用所有创新工具的固定清单，而是根据当前不确定性选择方法的最小系统。
